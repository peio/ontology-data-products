Description

  • A small OWL ontology describing the 50 constituents of the EURO STOXX 50 index: each company, its country, its ICB subsector and its FY2024 revenue with its reporting currency. Industries are reused from the ICB SKOS taxonomy; dataset provenance uses DCAT and PROV-O.

  • ICB is reused by reference (icb-skos.ttl is loaded alongside, not imported). FIBO and schema.org are aligned via rdfs:subClassOf without owl:imports, to keep the import closure small; instance data is additionally typed with the reused classes so the alignment does not depend on reasoning.

Classes

Company c

IRI https://graphwise.ai/ontology/estx50/Company
Description

  • Minted as a local subclass of schema:Corporation so that local constraints (disjointness, SHACL shapes) do not assert anything about schema.org itself. Instances are typed with both gw:Company and schema:Corporation, so the reuse is visible without a reasoner.

  • A company whose shares are listed on a stock exchange.
Scope Note

Membership of a particular index is not part of this definition; it is stated with gw:isConstituentOf, so a company stays a gw:Company when the index rebalances.
Sub Class Of schema:Corporation
In Domain Of

  • ICB subsector op
  • is constituent of op
  • revenue FY2024 dp
  • reporting currency dp
In Range Of has constituent op

Object Properties

country op

IRI https://graphwise.ai/ontology/estx50/country
Description

Links a company to the country the index provider assigns it to.
Scope Note

This is the index-assigned country, not legal domicile or headquarters. For example, Stellantis N.V. is legally domiciled in the Netherlands but is assigned to Italy.
Domain Company c
Range Country c

Datatype Properties

revenue FY2024 dp

IRI https://graphwise.ai/ontology/estx50/revenueFY2024
Description

  • Remark on the numbers: figures are approximate, are not converted to a common currency, and are not comparable across sectors (bank and insurer revenue is defined differently from industrial revenue). Totals are sums per reporting currency, as reported.

  • Company revenue for fiscal year 2024, in billions, in the company's reporting currency (gw:reportingCurrency), as reported in the source dataset.
Domain Company c
Range xsd:decimal

reporting currency dp

IRI https://graphwise.ai/ontology/estx50/reportingCurrency
Description

  • Revenue figures in different currencies must not be summed or ranked together without FX conversion, which is out of scope. Group by this property instead.

  • The ISO 4217 alphabetic code of the currency the company reports its revenue in, for example EUR or USD.
Domain Company c
Range xsd:string
