The same 50 rows, with shared meaning

The EURO STOXX 50 file is a table with 9 column headings. Its meaning lives in the headings' wording and in whoever reads them. The semantic layer gives each heading a defined term from a shared vocabulary, turns text values into links, and adds the facts the table cannot hold: the full industry hierarchy, index membership, provenance and validation rules.

Select a column heading to see what it becomes. The three shaded columns on the right are not in the file: the semantic layer adds them. Select a row to open that company.

A column heading is a few words, and what they mean is left to the reader. Behind each heading, the semantic layer holds labels, definitions, scope notes and rules, plus the definitions it inherits from shared vocabularies. Each bar counts the words of defined meaning behind a heading, coloured by where they come from. Select a heading to read them.
