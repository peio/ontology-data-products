Description

  • The EURO STOXX 50 constituents modelled with FIBO: each constituent is a FIBO publicly held company, the index is a FIBO equity index, countries are LCC countries, ICB subsectors are FIBO ICB classifiers, and FY2024 revenue is a FIBO monetary amount with its currency. This file holds only the five terms FIBO does not provide.

  • FIBO is referenced, not imported: the full FIBO adds about 132,000 triples to a 50-company dataset. Labels, definitions and parents of the FIBO terms used here are in fibo-extract.ttl, copied from FIBO 2026Q2 (QuickFIBOProd). ICB concepts are typed as FIBO ICB classifiers in icb-fibo-alignment.ttl. Instance data asserts the FIBO types directly, so no reasoner is needed to see them.

  • Under OWL's open world, FIBO's expectations the source cannot meet (legal name, incorporation date and jurisdiction, legal address, issued capital of a publicly held company) make the data incomplete, not inconsistent. The SHACL shapes do not enforce them.

revenue (billions) c

IRI https://graphwise.ai/ontology/estx50-fibo/Revenue
Description

  • Remark on the numbers: figures are approximate, are not converted to a common currency, and are not comparable across sectors (bank and insurer revenue is defined differently from industrial revenue). Totals are sums per currency, as reported.

  • Minted because FIBO has no corporate-revenue term. fibo-fnd-oac-own:Income was rejected: it means revenue received (cash), while reported revenue is recognised.

  • Revenue an organization reports for a fiscal year, as a monetary amount with exactly one amount, one currency and one reporting period. The amount (fibo-fnd-acc-cur:hasAmount) is in billions of the currency (fibo-fnd-acc-cur:hasCurrency): 34.2 with the currency Euro means EUR 34.2 billion.
Scope Note

FIBO reads fibo-fnd-acc-cur:hasAmount in the currency's units. The billions scale is a property of this class only: never read a gwf:Revenue amount as units, and never put a billions figure on a plain fibo-fnd-acc-cur:MonetaryAmount.
Sub Class Of fibo-fnd-acc-cur:MonetaryAmount

has revenue op

IRI https://graphwise.ai/ontology/estx50-fibo/hasRevenue
Description

  • No FIBO property links an organization to its revenue. Not functional: one revenue node per reporting period; the shapes require exactly one (FY2024).

  • Links an organization to a revenue figure it reports for a reporting period. The figure is in billions (see gwf:Revenue).

index-assigned country op

IRI https://graphwise.ai/ontology/estx50-fibo/indexAssignedCountry
Description

Links a company to the country the index provider assigns it to.
Scope Note

This is the index-assigned country, not legal domicile (cmns-org:isDomiciledIn) or headquarters. For example, Stellantis N.V. is legally domiciled in the Netherlands but is assigned to Italy.
Sub Property Of cmns-loc:hasCountry
Domain fibo-be-le-cb:PubliclyHeldCompany
Range lcc-cr:Country

is constituent of op

IRI https://graphwise.ai/ontology/estx50-fibo/isConstituentOf
Description

  • Deliberately not a subproperty of cmns-col:isMemberOf (in FIBO an equity index is a measure, not a collection) or cmns-col:isConstituentOf (meant for parts that are not discrete elements).

  • Links a company to an equity index whose basket includes a listed share the company issued (snapshot; no membership history).
Scope Note

A shortcut for FIBO's path: index fibo-fbc-dae-dbt:isBasedOn a fibo-ind-mkt-bas:BasketOfEquities, which cmns-col:hasMember a fibo-sec-sec-bsk:SecuritiesBasketConstituent, which cmns-col:comprises a fibo-sec-eq-eq:ListedShare, which fibo-fnd-rel-rel:isIssuedBy a fibo-sec-eq-eq:ShareIssuer role that cmns-rlcmp:isPlayedBy the company. The source has no share data, so only the shortcut is stated.
Domain fibo-be-le-cb:PubliclyHeldCompany
Range fibo-ind-mkt-bas:EquityIndex
