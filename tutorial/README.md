# Tutorial: The Data Product Pipeline

Leveraging AI to accelerate each step of building a data product.

| Step | Goal |
|------|------|
| [01 Elicitation](01-elicitation/) | Derive scope and competency questions from source documents |
| [02 Modelling](02-modelling/) | Build the ontology that answers those questions |
| [03 Mapping](03-mapping/) | Map source data to the ontology |
| [04 Ingesting](04-ingesting/) | Load the resulting RDF into the knowledge graph |
| [05 Indexing & Retrieving](05-indexing-retrieving/) | Make the data product searchable and queryable |
| [06 Integrating](06-integrating/) | Expose the data product to consumers and applications |
