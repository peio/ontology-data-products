## EURO STOXX 50 constituents (CSV2)

| | |
| --- | --- |
| Content | 50 rows, one per index constituent: company, website, country, ICB industry, ICB code, ICB concept IRI, revenue FY2024 (bn, approx.), reporting currency, country currency |
| Coverage | 8 countries, 11 ICB industries; revenue total 2,769.0 bn as reported |
| Source | Compiled from public company information |
| Licence | To be confirmed |
| Mapping | Company, Website, Country and Revenue are mapped. The three ICB columns are cross-checked against the subsector assignments, then derived rather than stored. The two currency columns are dropped (out of scope). |

Known limitations:

- ICB classification is at **industry level only** (2-digit code). The subsector comes from `icb-subsector-assignments.csv`.
- Revenue figures are approximate, in each company's reporting currency, not FX-normalised, and not comparable across sectors.

## ICB subsector assignments

| | |
| --- | --- |
| Content | 50 rows: company, 8-digit ICB subsector code, subsector name, one-line basis for the choice |
| Source | **Provisional.** Chosen from the ICB taxonomy labels based on each company's main business, not taken from FTSE Russell |
| Check | `map_csv.py` refuses any code that does not roll up (`skos:broader+`) to the industry stated in CSV2 |

To replace the provisional codes, edit this file and re-run the pipeline (see the [tutorial README](../README.md#run-it)). The borderline cases are listed in the [decision log](../decision-log.md#step-7-instances-and-testing).

## ICB taxonomy (SKOS)

| | |
| --- | --- |
| File | [`../ontology/icb-skos.ttl`](../ontology/icb-skos.ttl) |
| Content | Industry Classification Benchmark as a SKOS concept scheme `icb:scheme`: 249 concepts (11 industries, 20 supersectors, 45 sectors, 173 subsectors), with one `skos:Collection` per level |
| Namespace | `icb:` `https://graphwise.ai/taxonomy/icb/` |
| Version | 1.0.0 (`owl:versionIRI <https://graphwise.ai/taxonomy/icb/1.0.0>`), created 2026-10-28 |
| Source | `icb-codes-description.xlsx`, sheet "New ICB Codes and Description" (FTSE Russell) |
| Licence | ICB codes and names are the intellectual property of FTSE International Limited (FTSE Russell). This file only re-expresses them in SKOS; FTSE Russell's licence terms apply. |
| Transformations | Hierarchy derived from the code structure: each level appends two digits to its parent's code (`skos:broader` / `skos:narrower`). Concept IRI = namespace + ICB code; the code is also kept as `skos:notation`. |
